# Real-Time ICU Patient Monitoring (HPC)

Single-page project site. React 18, Vite, Tailwind CSS 3, lucide-react.

## Run

    npm install
    npm run dev

Build for production: `npm run build` (output in `dist/`).

## Edit before submitting

In `src/App.jsx`:
- `GITHUB_URL`: your repository link
- `UNIVERSITY`: your university name
- `SPEEDUP`: replace 1.9 and 3.4 with your measured 2-core and 4-core speedups
- `FAILOVER`: adjust timings to match your implementation
